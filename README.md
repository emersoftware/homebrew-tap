# emersoftware Homebrew tap

## Pacifico

Local archive and MCP recall for AI coding sessions.

```sh
brew install emersoftware/tap/pacifico && pacifico install
```

[Source and documentation](https://github.com/emersoftware/pacifico) · [Releases](https://github.com/emersoftware/pacifico/releases)

The formula installs a standalone binary for macOS or Linux, on ARM64 or x86-64. Bun and Node.js are not required.

Pacifico is inspired by and built on [nicknisi/sessions](https://github.com/nicknisi/sessions), under the MIT license.
